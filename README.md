# 3D 建模

## 案子

| 案子 | 說明 | 狀態 |
|------|------|------|

## 子目錄慣例

```
<case-name>/
  README.md      # 需求、尺寸、設計決策
  reference/     # 參考資料、照片、丟進來的 zip 解壓內容
  models/        # 建模檔（.stl / .step / .3mf / .f3d ...）
  docs/          # 量測、列印參數、組裝說明
```

構想成形後再各自開 GitHub repo。
