# photos/ 索引

命名規則：`<主體>_<面>_<角度/附註>.jpg`
- 主體：`peeler` = 撥紙器本體（要做的零件）；`module` = 整組列印頭模組（裝配脈絡用）
- 面：`outer` = 外側（有鋸齒撕紙邊那面朝上）；`inner` = 內側（有肋條、柱位那面朝上）；`side` = 側視
