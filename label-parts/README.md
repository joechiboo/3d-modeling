# label-parts — 標籤機自製零件

TSC TDP-225 系列（貼牌型號 DT2205）的替換／加強零件，3D 列印。
印表機：Bambu（AMS）。目前零件：撥紙模組（peel-off module，原廠料號 98-0390031-00LF）。

## 專案狀態
- 2026-08-20 開工：撥紙器左勾腳斷裂，決定自製加強版
- 2026-09-17 改為階梯式開發：每階只加一個特徵，印小件驗證後再疊
- 原廠件可購買（美國通路 $18.87；TSC 總部在新北新店，可問經銷商）

## 目錄
- `peeler/` OpenSCAD 原始檔（參數區在檔案開頭）
- `stl/` 輸出 STL（*_flat = 已放平可直接印）
- `renders/` 預覽圖、尺寸示意圖
- `photos/` 實物照片（**看 `photos/INDEX.md`：哪張照片能量哪個尺寸**）
- `scans/` 事務機掃描（目前的是文件模式，網點太重不可描邊；重掃請用照片/灰階模式＋白紙墊背）
